# Proposal: test-and-gate-hardening

## Why

Several tests and the architecture gate pass without proving what they
claim. The recorded-run fixture is gitignored (`.gitignore` `runs/` also
matches `tests/fixtures/runs/`), so a clean clone fails three test files and
the local copy is regenerated by the code it is meant to check.
`tests/test_skill.py` checks only option names, so `--sources filez`,
`--until rank`, or `fork <id>` without `--from` in `skill/SKILL.md` pass.
`scripts/check_architecture.py` misses `from wosarcher.adapters import x`
inside an adapter, lets `adapters/__init__.py` import every adapter, and lets
pure parts use stdlib file, process, and network I/O; it has no tests. A
handful of other tests are tautologies or lock in bugs (`n.d..` in MLA,
Chicago, and IEEE references; `evals.judge` exits 2 on `[1, 2,]`). These
are Fable review §5.1, §5.4, §5.5-5.8 and §8 items 7 and 11.

## What Changes

- Anchor the ignore rule (`/runs/`) and track
  `tests/fixtures/runs/20260101-000000-fixture/` in git; the generator
  writes no path of the machine that ran it.
- `tests/test_skill.py` parses every `wosarcher` line of `skill/SKILL.md`
  the way the CLI does: required arguments and options must be present,
  option types must parse, and the values of `--sources`, `--until`,
  `--from`, `--tone`, `--citation-marker`, `--reference-style`, and `--set`
  must be accepted by the same rules the CLI applies.
- `scripts/check_architecture.py`:
  - records `from P import name` as `P.name`, so adapter-to-adapter
    imports through the package are caught;
  - drops the `adapters/__init__.py` exemption (no package registry);
  - forbids stdlib I/O in pure parts: `os`, `subprocess`, `socket`,
    `shutil`, `tempfile`, `sqlite3`, `io`, `urllib.request`, `http.client`,
    `requests`, `aiohttp`, `importlib` (except `importlib.resources` in
    `prompts`), `pathlib.Path` (pure path classes stay allowed), the
    `open()` builtin, and `__import__`;
  - takes the package root as a parameter and gets its own test module.
- Reference entries never end in a doubled period (`n.d..`).
- `python -m evals.judge` records precision as missing for a malformed JSON
  list instead of exiting 2.
- Weak tests strengthened: Firecrawl credits, `doctor --json` exit code,
  progress throttling, SIGTERM grace before SIGKILL, CLI run test isolated
  from `WOSARCHER_*` variables, embeddings prefilter keeps the right chunks,
  truncated plan JSON.
- docs/development.md and docs/design.md ("Maintainability rules",
  "Evals") describe the new gate rules and the committed fixture.

## Capabilities

### New Capabilities
- `architecture-check`: the layering gate run by `scripts/check`: which
  internal imports each part may make, adapter independence, and the I/O
  ban on pure parts, with its own tests.

### Modified Capabilities
- `agent-skill`: "Commands match the CLI" also checks required arguments,
  required options, option types, and option values.
- `eval-replay`: "Recorded-run fixture" is tracked in git and holds no
  machine paths; "Judged precision" treats a malformed JSON list as
  unparsable.
- `report-writing`: "Reference list" entries end in exactly one period.

## Impact

- `.gitignore`, `tests/fixtures/runs/` (newly tracked, about 100 KB),
  `tests/fixtures/make_recorded_run.py`.
- `scripts/check_architecture.py`, new `tests/test_check_architecture.py`.
- `tests/test_skill.py`; `skill/SKILL.md` only if the stricter test finds
  an error.
- `src/wosarcher/stages/write.py` (reference formatters), `evals/judge.py`.
- Tests: `tests/adapters/test_firecrawl.py`, `tests/test_cli_doctor.py`,
  `tests/runner/test_parts.py`, `tests/server/test_queue.py`,
  `tests/test_cli_run.py`, `tests/stages/test_prefilter.py`,
  `tests/stages/test_plan.py`, `tests/stages/test_write.py`,
  `tests/evals/` (judge).
- docs/design.md sections "Evals" and "Maintainability rules";
  docs/development.md "Commands".
- No runtime behavior of the server, CLI, or UI changes apart from the
  reference punctuation and the judge.

## Non-goals

- The `seq`-across-stores fix and its test (change `server-robustness`).
- Wire-format tests for the LLM, retry, and rerank-scale fixes (change
  `provider-wire-formats`).
- Removing `config` from the stages' allow-list (Fable §6.3) and splitting
  `models.py` (§6.2).
- Making the recorded HTTP fixtures stricter (§5.5 last bullet) or covering
  the full runner empty-output and cancel matrix (§5.7 first bullet).
- Score and select test rewrites that depend on the reranker scale change
  (§5.6 score items).
